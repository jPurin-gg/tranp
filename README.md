# tranp

2人対戦の神経衰弱。別々のスマホからつないで遊ぶ。

## 遊び方

1. トップで「部屋を作る」
2. 出てきた URL を相手に送る
3. 相手が開いたら開始。部屋を作った側が先手

- スマホは横持ち。52 枚を 4 つの区画に分けて、画面には 1 区画（13 枚）だけ出る
- 手番の人が区画を移動すると（‹ › かスワイプ）、相手の画面も一緒に動く。手番でない側は見るだけ
- 2 枚めくって同じ数字（マークは問わない）なら取ってもう一度。違えば戻して交代
- 全部取ったら枚数の多い方が勝ち。「もう一回」で後手が先手になって再戦
- ページを再読み込みしても同じ席に戻れる。3 人目が URL を開くと「満席」

## 動かす

```sh
TRANP_INSECURE_COOKIE=1 go run ./cmd/tranp
```

`http://127.0.0.1:8080/` を開く。2 台で試すときはブラウザのタブや別プロファイルを 2 つ使えばよい。

環境変数:

| 名前 | 既定 | 意味 |
| --- | --- | --- |
| `TRANP_ADDR` | `127.0.0.1:8080` | 待ち受けアドレス |
| `TRANP_INSECURE_COOKIE` | （空） | `1` で平文 HTTP でも席の Cookie を送る。開発専用 |

### Docker

```sh
docker compose up -d --build                         # 本番（Cloudflare Tunnel の後ろ）
TRANP_INSECURE_COOKIE=1 docker compose up -d --build  # 手元で平文 HTTP
```

ポートはホストの `127.0.0.1:8080` にだけ開く。外へは cloudflared 経由で出す。

### テスト

```sh
go test ./...
```

## 仕組み

- Go の標準ライブラリだけ。外部モジュールなし。フロントは素の JS で、バイナリに埋め込む
- 部屋はサーバーのメモリに持つ（DB なし）。誰も見ていない部屋は 2 時間で消える。再起動で全部消える
- 配信は SSE（`GET /api/rooms/{id}/events`）、操作は POST。20 秒ごとに ping を流して Cloudflare の切断を防ぐ
- 席は部屋ごとの Cookie（`tranp_<id>`、HttpOnly）。伏せたカードの中身はクライアントに送らない
- 2 枚目をめくったあと、揃った場合は 0.9 秒、違った場合は 1.5 秒表示してからサーバー側で確定する

詳しくは [docs/技術選定.md](docs/技術選定.md)。
